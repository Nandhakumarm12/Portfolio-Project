# 🚀 Quick Start Guide

## Step 1: Download and Extract
Download `nandha-portfolio.zip` and extract it to your desired location.

## Step 2: Install Dependencies
```bash
cd nandha-portfolio
npm install
```

## Step 3: Run Development Server
```bash
npm run dev
```
Open http://localhost:3000 in your browser.

## Step 4: Customize
Edit `lib/data.ts` to update your personal information, projects, and blog posts.

## Step 5: Build for Production
```bash
npm run build
```

## Step 6: Deploy
Choose your deployment option (see README.md for detailed instructions).

---

## 📝 Important Files to Customize

1. **lib/data.ts** - Your personal info, experience, skills, projects, blogs
2. **app/sections/Hero.tsx** - Hero section text (if needed)
3. **public/images/** - Add your profile photo and project images
4. **app/globals.css** - Colors and styling

## 🔑 Environment Variables (Optional)

Create `.env.local` file:
```
OPENAI_API_KEY=your_key_here  # For AI chat features
```
